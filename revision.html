Key Facts

  • 1A = 1C/s  |  1V = 1J/C  |  1W = 1J/s
  • EMF = push (given by battery) | PD = drop (used by component)
  • Ammeter → series | Voltmeter → parallel
  • Bigger R in series → bigger voltage drop (V=IR)
  • Parallel total R always < smallest R

📝 Answering Questions

Command Words

WordWhat to do
State/NameDirect answer. No explanation.
DescribeWhat happens. No why.
ExplainWhat + why (use "because")
CompareUse "whereas" — both in same sentence
CalculateFormula → sub → answer + unit
SuggestReasonable guess (multiple valid)
JustifyAnswer + evidence
EvaluatePros + cons + conclusion

How to Explain

❌ "B1 is brighter."

✓ "B1 is brighter because it carries more current, so more energy is transferred per second."

Point → because → reason → result

Show Working

1. Formula: V = IR
2. Sub: V = 2 × 4
3. Answer: V = 8 V ← unit!

Full Sentences

❌ "Because it saves time."
✓ "It is beneficial because it saves time."

✍️ Writing Skills

PEEL Paragraph

  • Point — state your argument
  • Evidence — quote/example
  • Explanation — how it supports the point
  • Link — back to question / next point
