Hard Topics — Study Notes

1. Algebraic Fractions

Rule: ALWAYS factorise first, then cancel

  • Factor top and bottom separately
  • Cancel common brackets (not individual terms!)
  • You can only cancel FACTORS, never TERMS
⚠️ You CANNOT cancel: (x+3)/(x+5) ≠ 3/5. The x is part of the TERM, not a separate factor.
Example: Simplify (x²-9)/(x²+5x+6)
Top: x²-9 = (x+3)(x-3) [diff of squares]
Bottom: x²+5x+6 = (x+2)(x+3) [trinomial]
Cancel (x+3): = (x-3)/(x+2)

Adding/Subtracting Fractions

  1. Find the LCD (usually multiply the denominators)
  2. Multiply each fraction's top AND bottom to get the LCD
  3. Add/subtract the numerators
  4. Simplify if possible
Example: 2/(x+1) + 3/(x-2)
LCD = (x+1)(x-2)
= 2(x-2)/LCD + 3(x+1)/LCD
= (2x-4+3x+3)/LCD
= (5x-1)/((x+1)(x-2))

2. Completing the Square

Steps: x² + bx + c → (x + b/2)² + [c - (b/2)²]

  1. Halve the coefficient of x → that's p
  2. Square p → that's what you added
  3. Subtract what you added from the constant
Example: x² + 8x + 10
Half of 8 = 4, square it = 16
x² + 8x + 16 - 16 + 10
= (x+4)² - 6
So p=4, q=-6. Answer: (x+4)² - 6
To solve: x² - 6x + 5 = 0
(x-3)² - 9 + 5 = 0
(x-3)² = 4
x-3 = ±2
x = 5 or x = 1
⚠️ Common mistake: forgetting to subtract (b/2)² from the constant. If you add 16 inside the bracket, you must take 16 away outside!

3. Turning Points & Line of Symmetry

From factorised form: y = (x-a)(x-b)

  • x-intercepts: x = a and x = b (set each bracket = 0)
  • Line of symmetry: x = (a+b)/2 (midpoint of intercepts)
  • Turning point: sub x = (a+b)/2 back into the equation for y

From completed square: y = (x-p)² + q

  • Turning point: (p, q) — read it straight off!
  • Line of symmetry: x = p
  • If coefficient of x² is positive → ∪ → minimum
  • If coefficient of x² is negative → ∩ → maximum
Example: y = (x-3)² - 4
Turning point: (3, -4) [minimum]
Line of symmetry: x = 3
Shape: ∪ (positive x² → minimum)

4. Change of Subject (Hard)

When x appears on BOTH sides

  1. Multiply out any fractions
  2. Expand brackets
  3. Collect all x terms on ONE side
  4. Factor out x
  5. Divide
Example: Make x the subject: y = (2x+1)/(x-3)
y(x-3) = 2x+1
xy - 3y = 2x + 1
xy - 2x = 3y + 1   [collect x terms]
x(y-2) = 3y + 1   [factor out x]
x = (3y+1)/(y-2)
⚠️ Don't try to "undo" x when it's in two places. You MUST collect and factor.

Square root subjects

Make r the subject: A = πr²
r² = A/π
r = √(A/π)
