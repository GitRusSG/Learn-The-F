Hard Topics — Study Notes

1. Algebraic Fractions

Rule: ALWAYS factorise first, then cancel

  • Factor top and bottom separately
  • Cancel common brackets (not individual terms!)
  • You can only cancel FACTORS, never TERMS
⚠️ You CANNOT cancel: (x+3)/(x+5) ≠ 3/5. The x is part of the TERM, not a separate factor.
Example: Simplify (x²-9)/(x²+5x+6)
Top: x²-9 = (x+3)(x-3) [diff of squares]
Bottom: x²+5x+6 = (x+2)(x+3) [trinomial]
Cancel (x+3): = (x-3)/(x+2)

Adding/Subtracting Fractions

  1. Find the LCD (usually multiply the denominators)
  2. Multiply each fraction's top AND bottom to get the LCD
  3. Add/subtract the numerators
  4. Simplify if possible
Example: 2/(x+1) + 3/(x-2)
LCD = (x+1)(x-2)
= 2(x-2)/LCD + 3(x+1)/LCD
= (2x-4+3x+3)/LCD
= (5x-1)/((x+1)(x-2))

2. Completing the Square

Steps: x² + bx + c → (x + b/2)² + [c - (b/2)²]

  1. Halve the coefficient of x → that's p
  2. Square p → that's what you added
  3. Subtract what you added from the constant
Example: x² + 8x + 10
Half of 8 = 4, square it = 16
x² + 8x + 16 - 16 + 10
= (x+4)² - 6
So p=4, q=-6. Answer: (x+4)² - 6
To solve: x² - 6x + 5 = 0
(x-3)² - 9 + 5 = 0
(x-3)² = 4
x-3 = ±2
x = 5 or x = 1
⚠️ Common mistake: forgetting to subtract (b/2)² from the constant. If you add 16 inside the bracket, you must take 16 away outside!

3. Turning Points & Line of Symmetry

From factorised form: y = (x-a)(x-b)

  • x-intercepts: x = a and x = b (set each bracket = 0)
  • Line of symmetry: x = (a+b)/2 (midpoint of intercepts)
  • Turning point: sub x = (a+b)/2 back into the equation for y

From completed square: y = (x-p)² + q

  • Turning point: (p, q) — read it straight off!
  • Line of symmetry: x = p
  • If coefficient of x² is positive → ∪ → minimum
  • If coefficient of x² is negative → ∩ → maximum
Example: y = (x-3)² - 4
Turning point: (3, -4) [minimum]
Line of symmetry: x = 3
Shape: ∪ (positive x² → minimum)

4. Change of Subject (Hard)

When x appears on BOTH sides

  1. Multiply out any fractions
  2. Expand brackets
  3. Collect all x terms on ONE side
  4. Factor out x
  5. Divide
Example: Make x the subject: y = (2x+1)/(x-3)
y(x-3) = 2x+1
xy - 3y = 2x + 1
xy - 2x = 3y + 1   [collect x terms]
x(y-2) = 3y + 1   [factor out x]
x = (3y+1)/(y-2)
⚠️ Don't try to "undo" x when it's in two places. You MUST collect and factor.

Square root subjects

Make r the subject: A = πr²
r² = A/π
r = √(A/π)

Hard Topics — Detailed Notes

Take your time. Read every step. Understand before moving on.

1. Algebraic Fractions — Step by Step

What IS an algebraic fraction?

It's a fraction where the top and/or bottom contain algebra (letters). Like (x+3)/(x-1).

You treat them exactly like number fractions — same rules for simplifying, adding, multiplying.

How to Simplify

The key idea: factorise top and bottom, then cancel common BRACKETS.

Example 1: Simplify (x² - 9) / (x² + 5x + 6)

Step 1: Factor the top.
x² - 9 = x² - 3² = (x+3)(x-3)   ← difference of squares

Step 2: Factor the bottom.
x² + 5x + 6 → find two numbers that × to 6 and + to 5 → 2 and 3
= (x+2)(x+3)

Step 3: Cancel the common bracket.
(x+3)(x-3) / (x+2)(x+3) → cancel (x+3)
= (x-3)/(x+2) ✓
⚠️ THE #1 MISTAKE: Cancelling terms instead of factors.
(x+3)/(x+5) does NOT equal 3/5. You can't cross out the x.
You can only cancel a whole bracket that appears on BOTH top and bottom.

How to Add/Subtract Fractions

Same as numbers: get a common denominator, then add the tops.

Example 2: 2/(x+1) + 3/(x-2)

Step 1: LCD = (x+1)(x-2) — just multiply the two bottoms.

Step 2: Multiply each fraction:
First: 2/(x+1) × (x-2)/(x-2) = 2(x-2) / LCD
Second: 3/(x-2) × (x+1)/(x+1) = 3(x+1) / LCD

Step 3: Add the tops (keep the same bottom):
= [2(x-2) + 3(x+1)] / LCD
= [2x - 4 + 3x + 3] / LCD
= (5x - 1) / ((x+1)(x-2)) ✓

2. Completing the Square — Baby Steps

What's the point?

You're rewriting x² + bx + c into the form (x + something)² + something.
Why? Because from that form you can instantly read off the turning point of the graph.

The Method (3 steps)

StepWhat to doExample: x² + 8x + 10
1Halve the number in front of x8 ÷ 2 = 4
2Square that number4² = 16
3Write (x + half)² then subtract the square and add back the original constant(x+4)² - 16 + 10 = (x+4)² - 6
Example 3: Complete the square for x² + 8x + 10

Half of 8 = 4
4² = 16
x² + 8x + 10
= (x² + 8x + 16) - 16 + 10   ← added 16 inside, so subtract 16 outside
= (x + 4)² - 6

Answer: (x+4)² - 6   → p = 4, q = -6
Example 4: Solve x² - 6x + 5 = 0 by completing the square

Half of -6 = -3, square = 9
(x² - 6x + 9) - 9 + 5 = 0
(x - 3)² - 4 = 0
(x - 3)² = 4
x - 3 = ±√4 = ±2
x = 3 + 2 = 5   or   x = 3 - 2 = 1
⚠️ Common mistake: "I completed the square and got (x+4)² + 16 + 10."
NO! If you ADD 16 inside the bracket, you must SUBTRACT 16 outside. Think of it as borrowing — give it back!

Why it's useful: Finding the minimum/maximum

Once you have y = (x + p)² + q:

  • The smallest value of (x+p)² is 0 (a square is never negative)
  • So the smallest value of y is q
  • This happens when x = -p
y = (x+4)² - 6 → minimum value is -6 (when x = -4)

3. Turning Points & Line of Symmetry — Full Explanation

What is a turning point?

The point where the graph changes direction. For a ∪ shape it's the bottom (minimum). For a ∩ shape it's the top (maximum).

How to find it (3 different situations):

Situation A: Given y = (x - a)(x - b) [factorised form]

Example: y = (x - 1)(x - 5)

x-intercepts: Set each bracket = 0 → x = 1, x = 5

Line of symmetry: Midpoint = (1+5)/2 = x = 3

Turning point: Sub x = 3 back in:
y = (3-1)(3-5) = (2)(-2) = -4
Turning point = (3, -4)

Situation B: Given y = (x - p)² + q [completed square form]

Example: y = (x - 3)² - 4

Just read it off:
Turning point = (3, -4)
Line of symmetry = x = 3
Type: Minimum (because the x² coefficient is positive → ∪ shape)

Situation C: Given y = ax² + bx + c [general form]

You MUST complete the square first to get it into form B. Or use: line of symmetry = x = -b/(2a).

How to tell if it's a max or min?

If the number in front of x² is...ShapeTurning point is...
Positive (e.g. x², 2x², 0.5x²)∪ (smile)Minimum (bottom)
Negative (e.g. -x², -3x²)∩ (frown)Maximum (top)

4. Change of Subject — When x is on Both Sides

The problem

Normal "make x the subject" is easy: just undo operations. But when x appears in two places, you can't undo — you have to collect and factor.

The method (5 steps)

  1. Multiply out any fractions (multiply both sides by the denominator)
  2. Expand all brackets
  3. Move all terms with x to ONE side, everything else to the OTHER side
  4. Factor out x
  5. Divide both sides by what's left in the bracket
Example: Make x the subject of y = (2x + 1)/(x - 3)

Step 1: Multiply both sides by (x-3):
y(x - 3) = 2x + 1

Step 2: Expand:
xy - 3y = 2x + 1

Step 3: Move x terms to left, non-x to right:
xy - 2x = 3y + 1

Step 4: Factor out x:
x(y - 2) = 3y + 1

Step 5: Divide:
x = (3y + 1)/(y - 2) ✓
⚠️ The trick you MUST remember: In step 3, you're literally just moving terms across the = sign (changing their sign). In step 4, x is the common factor — pull it out. That's it. Don't overthink it.

Square root subjects

Make r the subject: A = πr²
÷ π: A/π = r²
√ both sides: r = √(A/π)

Make t the subject: s = ½at²
× 2: 2s = at²
÷ a: 2s/a = t²
√: t = √(2s/a)

5. Quick Memory Aids

  • Fractions: Factorise First, Cancel Carefully (F.F.C.C.)
  • Completing square: "Halve it, square it, take it away"
  • Turning point from (x-p)²+q: The point is literally (p, q) — just read it
  • Max or min: Positive = smile ∪ = min. Negative = frown ∩ = max.
  • Change of subject: "Collect, Factor, Divide" (C.F.D.)
  • Line of symmetry: Always halfway between the x-intercepts
